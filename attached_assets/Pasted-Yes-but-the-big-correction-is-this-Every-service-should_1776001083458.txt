Yes — but the big correction is this:

Every service should have its own question set.
Not every service should be auto-quoted.

That is how you keep it simple for homeowners and still control risk.

The doctrine I’d use

For every service, every question must do one of these:
	•	add labor
	•	multiply labor
	•	add a fee
	•	flag/disqualify

For every service, risk must be controlled by one of these:
	•	a priced question
	•	a “Not sure” buffer
	•	a required photo
	•	manual review / no instant price

So the real rule is not “ask everything.”
The real rule is:

No uncontrolled risk is allowed to pass through the funnel.

Betty-safe rules

Use these on every service:
	•	Max 4–6 customer questions before photos
	•	No jargon
	•	Use plain homeowner language
	•	Any technical question gets Not sure
	•	Any dangerous/unclear condition gets manual review
	•	Never ask two questions that mean the same thing
	•	Never ask a question unless at least one answer changes price or routing

Three quote modes

1. Instant-price

Safe, routine, predictable.

2. Instant-price + photo gate

Can still quote, but only if customer uploads a photo and no red flags show up.

3. Diagnostic / manual quote only

Customer can answer questions, but they do not get a real instant price. They get:
	•	diagnostic fee
	•	request quote
	•	site visit required

Universal question patterns to reuse inside each service

These are the only patterns you really need.
Duplicate them into each service-specific set.

1. Quantity

“How many?”
	•	add hours
	•	add materials

2. Existing vs brand new

“Is there already a light / fan / outlet / hookup there now?”
	•	existing = lower labor
	•	brand new = added labor

3. Distance from power source

“Is this in the same room, next room, or farther away?”
	•	adds hours

4. Access difficulty

“Can we reach it from an attic / crawlspace, or would the walls/ceiling need to stay closed?”
	•	add hours or multiplier
	•	not sure = buffer

5. Height

“How tall is the ceiling?”
	•	multiplier
	•	over threshold = disqualify

6. Wall / ceiling finish

“Drywall, tile, brick, plaster, wood?”
	•	multiplier or fee

7. Outdoor / trenching exposure

“On the house, on a pole, across the yard, or underground?”
	•	add hours / fee / manual review

8. Safety red flag

“Any burning smell, buzzing, sparks, water damage, or melted parts?”
	•	flag / disqualify

9. Photo requirement

Used when words alone are not reliable
	•	panel
	•	existing fixture
	•	location
	•	appliance area
	•	exterior mounting spot

Hard disqualifiers you should use across services

These should stop auto-quoting immediately:
	•	Ceiling over 20 ft
	•	Burning smell / sparking / melted device
	•	Water intrusion into electrical equipment
	•	Unknown damaged panel condition from photo
	•	Aluminum wiring / knob-and-tube / fuse box on services not built for it
	•	Detached structure with trenching on services that are not trench-priced
	•	Pool/spa equipment without clear scope
	•	Commercial property if this estimator is residential-only
	•	Multi-family / condo where access rules complicate the job
	•	Customer says “not sure” on too many core risk questions

Very important wording fix

Do not ask technical questions like:
	•	“Is there a fan-rated box?”
	•	“Is it a 3-way?”
	•	“Do you have attic access?”
	•	“Is it a dedicated 240V circuit with two-pole breaker capacity?”

Instead ask:
	•	“Is there already a ceiling fan there now?”
	•	“Does this light turn on from one switch or two different switches?”
	•	“Can we reach above this ceiling from an attic?”
	•	“Is your breaker box in the same area as the charger, next room, or farther away?”
	•	“Please upload a photo of the breaker box.”

That is the Betty test.

What I’d tell Replit

Use this as the operating rule:

Build a separate question set for every service.
Do not rely on customers to know electrical terms.
Every question must either change price, add uncertainty buffer, require a photo, or route to manual review.
Any service with high scope variance, hidden access risk, trenching risk, panel risk, or diagnostic uncertainty must not return a blind instant price.
For technical unknowns, auto-add a “Not sure” option that applies a buffer and flags the quote for review.
Keep each service to 4–6 homeowner-safe questions max, then use photos and routing rules to control the rest.
