TICKET 8 — AUDIT LOG + CHANGE HISTORY

Objective:
Add an immutable audit log in Google Sheets and a CRM Audit page so every meaningful change is traceable (who/what/when/from→to).

Rules:
- Preserve section divider comments. Do NOT remove existing structural comments.
- File size limit is removed. Prioritize readability over splitting.
- Keep existing behavior working; only add audit functionality.
- Audit should be append-only and never edit previous audit rows.

Implement:
1) Auto-setup:
- On server startup, ensure a Sheet tab named "Audit" exists.
- Ensure headers exist exactly in this order:
  audit_id, created_at, actor, action, entity_type, entity_id, field, old_value, new_value, note, source, request_id

2) Backend helper:
- Create lib/audit.js exporting async logAudit(entry)
- logAudit appends 1 row to Audit tab.
- audit_id = "AUD-" + Date.now()
- created_at = new Date().toISOString()
- request_id = random string per request (ok to generate at handler start and pass through)

3) Wire audit logging into existing flows:
- Lead creation: action=lead.create (entity_type=lead, entity_id=lead.id, field="*", new_value can be JSON summary)
- Lead updates (status, schedule, assigned_to, deposit_override, invoice/paid fields): log one audit row per changed field with old_value/new_value.
- Deposit gate blocks: log action=lead.status.blocked with note describing missing requirement.
- Quotes create: action=quote.create (entity_type=quote, entity_id=quote_id, note includes lead_id)
- Time create: action=time.create
- Expense create: action=expense.create

Actor/source:
- For now actor can be "system" (or "Tristan") and source should be the page name (crm-leads, crm-new, crm-schedule, crm-dashboard, quote).
- It’s OK to hardcode actor="system" until login exists.

4) New API:
- GET /api/audit?entity_id=&action=&limit=
- Returns latest entries (newest first). Default limit 200.

5) New page:
- pages/crm-audit.html + pages/js/crm-audit.js
- Route /crm/audit
- Table shows last 200 audit entries newest-first.
- Filters: entity_id text box + action dropdown + refresh.

6) Update nav on CRM pages:
- Add "Audit" link in the CRM nav (replace Home link if still present).

Deliverables:
- Working /crm/audit page
- Working /api/audit
- Audit tab created/headers ensured automatically
- Audit rows appear for lead create, lead update, status change, schedule change, deposit block, quote create, time log, expense log
