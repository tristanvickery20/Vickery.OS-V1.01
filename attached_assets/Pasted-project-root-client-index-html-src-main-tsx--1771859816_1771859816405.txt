Tech Stack
Frontend: React + TypeScript, Vite bundler
Styling: Tailwind CSS v3 with CSS custom properties (HSL color system)
UI Library: Shadcn/UI components (Radix primitives under the hood)
Animations: Framer Motion for page transitions, expand/collapse, hover effects
Icons: Lucide React
Data fetching: TanStack Query v5
Routing: Wouter (lightweight React router)
Backend: Express.js + Drizzle ORM + PostgreSQL
Brand Identity & Color System
All colors are defined as CSS custom properties using HSL values without the hsl() wrapper (Tailwind consumes them with its own hsl() function for alpha support).

Primary Brand Color: Vickery Dark Blue
--primary: 220 100% 25%    /* Deep navy blue - the signature Vickery Electric blue */
This translates to approximately #000080 / rgb(0, 0, 128) range -- a rich, dark, authoritative blue.

Typography
Two Google Fonts, loaded via CSS import:

@import url('https://fonts.googleapis.com/css2?family=Outfit:wght@400;500;600;700;800&family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap');
Display / Headings: 'Outfit' -- geometric, modern, bold. Used for h1-h6, prices, step numbers. Applied via font-display class or font-family: var(--font-display).
Body / UI text: 'Plus Jakarta Sans' -- clean, professional, very readable. Applied to body via font-family: var(--font-body).
All headings get: font-bold tracking-tight text-foreground.

Page Transitions
All step transitions use Framer Motion's AnimatePresence with mode="wait":

Enter from right: initial={{ opacity: 0, x: 20 }}, animate={{ opacity: 1, x: 0 }}
Exit to left: exit={{ opacity: 0, x: -20 }}
Step 1 enters from left instead: initial={{ opacity: 0, x: -20 }}
On every step change, window.scrollTo({ top: 0, behavior: 'smooth' }) fires

Summary for Your CRM Prompt
Build a Vickery Electric CRM using React, TypeScript, Tailwind CSS, and Shadcn/UI components. Use the "Outfit" font for headings/display text and "Plus Jakarta Sans" for body text (both from Google Fonts). The primary brand color is a deep dark blue at HSL(220, 100%, 25%). Use HSL CSS custom properties for all colors. The overall feel is clean, modern, and premium -- generous white space, large rounded corners (12-16px on cards, 12px on buttons), soft shadows with blue-tinted shadow-primary/20, semi-transparent glass effects (bg-white/80 backdrop-blur-md), and subtle gradient backgrounds (from-background via-blue-50/50 to-indigo-50/30). The header is sticky with a frosted glass effect, featuring the Vickery Electric logo on the left. Interactive elements use Framer Motion for micro-animations (scale on hover/tap, slide transitions between views). Selected states use a light primary tint (bg-primary/5) with a primary border. Dark inverted cards (bg-foreground text-background) are used for cost/price displays. The design system is built on Shadcn/UI primitives with Radix under the hood.
