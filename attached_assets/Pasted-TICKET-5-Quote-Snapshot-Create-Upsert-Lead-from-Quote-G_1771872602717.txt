TICKET 5 — Quote Snapshot + Create/Upsert Lead from Quote

Goal:
When a quote is calculated, automatically create or update a Lead and store a Quote Snapshot JSON so quotes are auditable forever.

1) Google Sheet:
Create tab "Quotes" if missing (auto-create on startup) with headers:
- quote_id
- created_at
- lead_id
- service_key
- pricing_version
- quoted_price
- quote_snapshot_json

Also ensure Leads tab has headers (auto-add if missing):
- pricing_version
- last_quote_id
- quote_snapshot_json

2) Backend API:
Create POST /api/quotes/create
Request body example:
{
  "name": "Customer Name",
  "phone": "555",
  "address": "123",
  "service_key": "recessed_light",
  "inputs": { "lights": 6 }
}

Behavior:
- Run deterministic pricing using existing pricing.js for recessed lights.
- Build snapshot JSON:
{
  quote_id,
  created_at,
  service_key,
  inputs,
  engine:{ pricing_version:"v1", rates_used:{} },
  totals:{ total, labor, material, unitTotal },
  line_items:[...optional],
  lead:{ name, phone, address }
}

- Find existing lead by phone+address (or phone only if address missing). If found, update that lead; else create new lead.
- Update lead fields:
  - quoted_price = totals.total
  - pricing_version = snapshot.engine.pricing_version
  - last_quote_id = quote_id
  - quote_snapshot_json = JSON.stringify(snapshot)
  - status remains unchanged if already past Lead stage; otherwise set to "Estimate Sent"

- Append row to Quotes tab with the snapshot JSON.

Return:
{ ok:true, lead_id, quote_id, total }

3) Frontend:
Update pages/quote.html so the Calculate button still shows price,
BUT also includes a "Save as Lead" button that calls POST /api/quotes/create with name/phone/address + inputs.
Show returned lead_id + link to /crm/leads.

4) CRM:
Add a "View Snapshot" link/button on crm-leads page that opens /crm/lead?id=LEAD-xxx
Create new page pages/crm-lead.html that fetches that lead and displays quote_snapshot_json formatted.

Keep all files <=200 lines by splitting helpers into pages/js/ if needed.
Do not break existing quote calculation endpoint.
