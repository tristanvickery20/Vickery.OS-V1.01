4) API ROUTES
Create these routes:
- POST /api/sms/send
  Sends one SMS immediately after permission checks.

- POST /api/sms/schedule
  Queues an SMS for later send.

- POST /api/sms/approve/:queueId
  Approves a queued marketing SMS.

- POST /api/sms/cancel/:queueId
  Cancels queued SMS.

- POST /api/sms/crew-action/:jobId/:action
  One-tap crew actions:
  - ON_THE_WAY
  - WE_ARE_HERE
  - RUNNING_LATE
  - JOB_COMPLETE
  These must send operational templates immediately if service_sms_opt_in is true.

- POST /api/webhooks/sms/smsgate
  Receives SMSGate webhooks.
  Must:
  - use raw request body
  - verify HMAC-SHA256 with X-Signature and X-Timestamp
  - reject invalid signatures
  - handle inbound customer replies
  - handle sent/delivered/failed status updates
  - upsert messages in sms_messages

- GET /api/sms/conversation/:contactId
  Returns conversation history

- GET /api/sms/queue
  Returns queued and pending approvals

5) BUSINESS RULES
Implement these guardrails:
- Operational messages require:
  - valid phone number
  - no revoke flag
  - service_sms_opt_in = true
- Marketing messages require:

  - no revoke flag
  - marketing_sms_opt_in = true

  - stop future marketing sends immediately
- If customer replies HELP:
