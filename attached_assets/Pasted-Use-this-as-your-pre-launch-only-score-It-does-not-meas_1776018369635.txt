Use this as your pre-launch only score.

It does not measure whether the business is proven.
It measures whether the business is designed tightly enough to launch without obvious self-inflicted chaos.

Vickery Pre-Launch Readiness Score

“VPRS-100”

1) What this score is for

This score answers:

“How ready is this business to launch from a design, structure, and systems standpoint before spending money or running real jobs?”

It does not answer:
	•	whether leads will actually come in
	•	whether people will buy
	•	whether margins will hold in reality
	•	whether you should quit your job

It is a readiness score, not a market validation score.

⸻

2) Exact formula

Step 1: Score every criterion from 0 to 5

Each criterion gets points using this exact framework:

WQOBT scoring

For every criterion, give 1 point for each item below:
	•	W = Written
It exists in writing in one authoritative place.
	•	Q = Quantified
It has actual numbers, rules, limits, thresholds, or defined logic.
	•	O = Owned
One person or one system is clearly responsible for it.
	•	B = Backup
There is an exception path, fallback rule, or backup plan.
	•	T = Tabletop-tested
You have run a fake scenario through it and it held up without major confusion.

Criterion score

Criterion Score = W + Q + O + B + T

So each criterion is:
	•	0 = nonexistent
	•	1 = vague idea
	•	2 = rough draft
	•	3 = documented but fragile
	•	4 = solid and operational
	•	5 = fully launch-ready on paper

⸻

Step 2: Calculate each category score

For each category:

Category % = (Sum of criterion scores) / (5 × number of criteria)

Then:

Weighted Category Score = Category % × Category Weight

⸻

Step 3: Add all weighted category scores

Base Score = Sum of all Weighted Category Scores

This gives you a number from 0 to 100.

⸻

Step 4: Apply penalties

Final formula

Final Readiness Score = Base Score – Contradiction Penalty – Critical Unknown Penalty – Single-Point-of-Failure Penalty

⸻

3) Penalties

A. Contradiction Penalty

A contradiction is when two parts of the business disagree in a way that changes execution.

Examples:
	•	service area says Beaumont allowed, scheduler says Beaumont approval only
	•	estimator says deposit optional, ops says deposit required
	•	quote says no travel fee, pricing rules say travel fee
	•	CRM status flow conflicts with actual field workflow

Score it like this:
	•	Major contradiction = -2 each
	•	Minor contradiction = -1 each

Major contradiction areas:
	•	licensing/authority
	•	pricing
	•	deposits/payment
	•	scheduling
	•	service area
	•	who does what
	•	what is offered/not offered

Cap this penalty at 10.

⸻

B. Critical Unknown Penalty

A critical unknown is something essential that is still unanswered.

Examples:
	•	no final master/electrical authority structure
	•	no min ticket
	•	no launch service list
	•	no owner pay rule
	•	no quote approval rule
	•	no go/no-go launch rule

Score it like this:
	•	Critical unknown = -2 each

Cap this penalty at 12.

⸻

C. Single-Point-of-Failure Penalty

This is a dependency that can cripple launch if it breaks and there is no backup.

Examples:
	•	one master, no backup plan
	•	one pricing sheet, no version backup
	•	one phone line, no forwarding backup
	•	one CRM login, no admin recovery
	•	one payment path, no backup collection method

Score it like this:
	•	Critical single point of failure with no backup = -1 each

Cap this penalty at 8.

6) How to give the T “Tabletop-tested” point

You said this must work without real jobs or spending money, so this is how “tested” works.

A criterion gets the T point only if it survives a fake scenario.

Tabletop-test rule

You run a scenario from start to finish using your actual docs, scripts, sheets, and rules.

You only get the T point if:
	•	no major ambiguity appears
	•	no key decision has to be made from memory
	•	no contradiction appears
	•	the next step is obvious
	•	the output is usable

If you had to say:
	•	“we’d figure that out”
	•	“depends”
	•	“I know what I mean but it’s not written”
	•	“that’s not built yet”
	•	“we’ll decide later”

then no T point.

11) Exact spreadsheet layout

Make a sheet with these columns:
	•	Category
	•	Category Weight
	•	Criterion
	•	W
	•	Q
	•	O
	•	B
	•	T
	•	Criterion Score
	•	Criterion %
	•	Category %
	•	Weighted Score
	•	Notes
	•	Contradiction?
	•	Critical Unknown?
	•	Single Point of Failure?

Formulas

Criterion Score

=SUM(W: T)
If W is column D and T is column H, then:
=SUM(D2:H2)

Criterion %

=I2/5

Category %

Average of all criterion % values in that category

Weighted Score

=Category % × Category Weight

Base Score

Sum of all Weighted Scores

Penalties

=(2 × Major Contradictions) + (1 × Minor Contradictions) + (2 × Critical Unknowns) + (1 × Single Point Failures)

You can separate major/minor contradiction counts in summary cells.

Final Readiness Score

=MIN(Overall Cap, Base Score - Total Penalties)

12) My recommendation for how strict you should be

Be mean when you score it.

Do not give yourself the point unless it is actually true.

Examples

Bad self-scoring

“We basically know our service area.”
That is not quantified. No Q point.

Bad self-scoring

“I’ll handle that.”
That is not owned unless it is explicitly written. No O point.

Bad self-scoring

“We have a backup.”
Not unless the backup is written and usable. No B point.

Bad self-scoring

“I’ve thought through it a lot.”
That is not tested. No T point.

13) The fastest way to use it

Do this in order:
	1.	Fill every criterion with WQOBT scores
	2.	Count penalties honestly
	3.	Apply the caps
	4.	Get your final number
	5.	Circle every criterion scoring 0, 1, or 2
	6.	Fix those first
	7.	Re-score

That gives you a brutally honest pre-launch number.
