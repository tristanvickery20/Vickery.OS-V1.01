VE OS ALIGNMENT SOURCE

This repo is the CRM / operating system for Vickery Electric, a launch-stage residential electrical service business.

The system is not a generic CRM. It is the operating command center for a residential electrical service company that uses:
- Google Sheets as the source of truth for estimator/pricing data
- A customer-facing instant quote flow
- CRM lead/quote/schedule handoff
- Quote snapshot JSON storage
- Risk flags, photo gates, manual review gates, and service assumptions

Main doctrine:
- Predictable
- Profitable
- Replicable
- Low-chaos
- Structure creates freedom
- Chaos is a tax on profit

The owner is not a coder. Make practical, visible, working changes. Do not make vague backend-only changes that cannot be verified in the UI.

IMPORTANT BUSINESS LOGIC

Vickery Electric wants to instant quote as much as possible.

Do not turn everything into “site visit required.”

Use this approach:

Low-risk routine work:
- Show instant price.
- Allow booking if no risky answers.

Medium-risk work:
- Show instant price or estimated price.
- Require photos before booking or mark review_required.
- Allow lead/quote creation.

High-risk work:
- Collect intake.
- Show “review required” or estimated range if supported.
- Block final booking until reviewed.
- Still save the quote/session/lead cleanly.

Never blindly auto-book:
- unsafe symptoms
- burning smell
- sparking
- hot panel/breaker
- panel/service upgrades
- fuse box conversion
- generator work
- trenching
- hot tub circuits
- unclear panel capacity
- full panels
- old/damaged/recalled panel brands
- exterior underground work
- work likely requiring permit/master review
- customer “not sure” on critical safety questions

CUSTOMER EXPERIENCE PRINCIPLE

Do not make the form feel like a giant interrogation.

Use conditional questions where the code supports it.

If conditional logic does not exist yet, add it carefully using the smallest practical change.

Customer-facing wording should feel like:

“We ask these questions so we can price this like we already walked the job. If you’re not sure, choose ‘Not sure’ and we may ask for photos before confirming.”

Photo-gated wording should feel like:

“Your instant price is based on these answers. For this job type, photos help us confirm the price before booking.”

Review-required wording should feel like:

“Based on your answers, this needs review before final booking. You can still submit it now and we’ll confirm the price/scope.”
