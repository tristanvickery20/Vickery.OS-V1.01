2) CREATE NEW MODULE: lib/quoteEngineV2.js

Function:
calculateQuoteV2({
  assembly,
  qty,
  selectedDriverOptions,
  rates,
  serviceAreas,
  zip
})

Pricing logic:

labor_unit = blended_labor_hours || baseline
labor_hours = labor_unit * qty

Apply driver labor multipliers.

drive_hours:
- use assembly.drive_time_hours
- else derive from travel_zone and Rates_Rules
- else fallback 0.25

crew rate:
parse Config.defaultLaborMix (e.g. 1JW+1AP)
crew_loaded_hourly =
jw*journeymanLaborBurden +
ap*apprenticeLaborBurden

labor_cost = total_hours * crew_loaded_hourly

materials:
sum AssemblyItems where item_type=material:
qty_per_unit * qty * Materials.base_cost

Apply material multiplier.
Apply waste (materialWastePct).
Apply materialsMarkup.

overhead_cost =
(labor_cost + material_sell) * (overheadRate/100)

risk:
risk_class multiplier from Rates_Rules
dynamic multiplier from Assemblies
risk_multiplier = class * dynamic

risk_cost_add =
(labor_cost + material_sell) * (risk_multiplier - 1)

true_cost =
labor_cost +
material_sell +
overhead_cost +
risk_cost_add +
base_fee

target_margin default 30%

sell =
true_cost / (1 - target_margin)

sell =
max(sell, minimumServiceFee, minQuoteTotal)

Add travel_fee from CRM ServiceAreas if ZIP present.

Round final price to nearest $5.

Return EXACT same JSON keys as current engine:
{
  final_price,
  hours,
  labor_cost,
  overhead_cost,
  material_allowance,
  fees,
  travel_fee,
  address_provided,
  photo_required,
  evaluation_flag,
  pricing_version: "v2"
}
