ISSUE 2 — Lead detail estimated materials are showing per-assembly quantities, not total job quantities

On Lead Detail, the Estimated Materials section does appear, but the quantities are wrong/confusing.

Current example shown:
- 6" LED recessed downlight
  1 each — Base service
- Device box (old work)
  1 each — Base service
- NM-B 12/2 cable
  0.1 each — Base service
- Wire connectors
  0.05 each — Base service
- Electrical tape
  0.02 each — Base service

Problem:
This looks like it is showing raw per-assembly or fractional base quantities instead of a usable total pull list.

Expected:
Estimated Materials should show total required materials for the whole quote/job, not “per assembly” math.

Examples:
- If the customer quotes 3 recessed lights, the material list should show 3 recessed lights, 3 boxes, total cable allowance, total connectors, etc.
- If the quote includes a receptacle swap and a light install, the material list should include the receptacle materials plus the light materials together.
- Duplicate materials across assemblies should be combined into one total line.
- The label should not say “1 each” if that number is only the base quantity per assembly.
- Fractional material quantities should be converted into a usable pull-list format where appropriate.

Desired behavior:
The material list should act like a real preliminary pull list:
- aggregate all assemblies in the quote/job
- multiply by quantity
- combine duplicate material items
- show final total quantity
- show the correct unit
- avoid weird “0.05 each” / “0.1 each” display when the crew needs a practical material count or allowance
- keep notes/descriptions if useful, but the main quantity must be the total needed for the job

Acceptance test:
Create one Recessed Lighting Installation quote with qty 1.
Lead Detail and Crew Job Detail should show the same total material list.
Then create another quote with qty 3.
The material quantities should increase correctly.
Then create a mixed quote, such as receptacle replacement plus light install.
The material list should include all materials from both services and aggregate duplicates.
