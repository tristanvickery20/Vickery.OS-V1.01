API RESPONSE SHAPES

A) GET /api/clients/:id
Return:
{
  ok: true,
  client: {
    id, name, phone, email, sms_opt_in, job_description, status_code,
    created_at, updated_at, last_activity_at,
    primary_property: { id, address_line1, address_line2, city, state, zip, lat, lng, notes } | null
  }
}

Primary property selection rule:
- property where client_id matches AND is_primary truthy
- else first property (or most recently updated/created)
- else null

B) GET /api/clients/:id/requests
Return list of Requests rows where client_id matches, sorted by created_at DESC.
Fields:
id, created_at, updated_at, summary, status_code, deposit_required, deposit_received, estimated_value

C) GET /api/clients/:id/quotes
Return list where client_id matches, sorted by created_at DESC.
Fields:
id, created_at, status_code, quoted_price, service_key, pricing_version, request_id

D) GET /api/clients/:id/jobs
Return list where client_id matches, sorted by created_at DESC.
Fields:
id, created_at, status_code, description, completed_at, request_id

E) GET /api/clients/:id/notes
Return list where entity_type='client' AND entity_id=:id sorted created_at DESC.
Fields:
id, created_at, author, body

F) GET /api/clients/:id/attachments
Return list where entity_type='client' AND entity_id=:id sorted created_at DESC.
Fields:
id, created_at, file_url, file_type, category, uploaded_by
