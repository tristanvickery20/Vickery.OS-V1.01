REPLIT TICKET 1 — Apps Script Lead Create (Secure Write Gateway)

OBJECTIVE
Implement a backend route in our Node server that securely creates a Lead row in Google Sheets by calling our Apps Script Web App (no Google credentials in the browser).

CONTEXT
This repo is Vickery Electric OS v1 (CRM + future quote site). Google Sheets is the data spine. Apps Script is the secure write gateway. We are NOT restarting. Do NOT break existing CRM pages/routes.

CONSTRAINTS (NON-NEGOTIABLE)
- Do NOT expose any Google service account credentials to the frontend.
- All writes must go through Apps Script Web App using a shared secret.
- No file > 200 lines. If needed, create small modules (lib/* or api/*).
- Keep existing working routes:
  - Pages: /, /crm/dashboard, /crm/leads, /crm/new, /crm/schedule
  - APIs: /api/leads (GET/POST), /api/leads/update (PATCH), /api/techs (GET), /api/dashboard (GET), /health
- Mobile-first; keep it simple.

REQUIRED ENV VARS (add to Replit Secrets)
- APPS_SCRIPT_URL = <PASTE MY APPS SCRIPT WEB APP URL>
- APPS_SCRIPT_SECRET = <PASTE MY SHARED SECRET STRING>

APPS SCRIPT EXPECTATION
- Accepts POST JSON body with a "secret" field
- Action field: action="lead.create"
- Returns JSON: { ok: true, lead_id: "...", row: <number> } or { ok:false, error:"..." }

IMPLEMENTATION TASKS
1) Create backend helper to call Apps Script:
   - File: lib/appsScriptClient.js
   - Export: postToAppsScript(payload)
   - Uses process.env.APPS_SCRIPT_URL
   - Adds Content-Type: application/json
   - Returns parsed JSON response
   - Throws useful errors if non-200 or invalid JSON

2) Create API route handler:
   - File: api/apps-lead-create.js
   - Export: handleAppsLeadCreate(req, res)
   - Accepts POST /api/apps/lead
   - Reads JSON body
   - Adds: secret: process.env.APPS_SCRIPT_SECRET
   - Adds: action: "lead.create"
   - Forwards to Apps Script using lib/appsScriptClient.js
   - Responds with the Apps Script JSON result

3) Wire route in index.js:
   - Route: POST /api/apps/lead  -> handleAppsLeadCreate
   - Use startsWith robustness: req.url.startsWith("/api/apps/lead")

4) Add a quick manual test page (very small):
   - File: pages/test-apps.html
   - Simple form: name, phone, address, job_type (small_job/project), estimated_value, notes
   - Button "Send to Apps Script"
   - On click: fetch POST /api/apps/lead with the fields
   - Show response JSON on screen

5) Add page route in index.js:
   - GET /test-apps -> serves pages/test-apps.html
