TICKET 13 — NOTES + PHOTOS (ATTACHMENTS) MVP (CREATE + LIST) + CLIENT LAST-ACTIVITY “TOUCH” + LIGHTBOX

CONTEXT / NON-NEGOTIABLES
- Google Sheets is the single source of truth.
- No paid services required for uploads in this ticket.
- Keep it simple and deterministic:
  - MVP “upload” = user provides a file URL (or we accept base64 only if you already have storage; do NOT add storage vendors).
- Every create/mutation must:
  1) Write the row to the correct sheet tab
  2) Write an Audit entry (fire-and-forget; audit failures must not break the operation)
  3) Update clients.last_activity_at = now() (touchClient)
- Everything is auth-protected except /quote.
- Ticket 12 already reads Notes + Attachments; Ticket 13 adds CREATE + UX polish (lightbox + add forms).

GOAL
On Client Detail page:
- Notes tab: add note + list notes newest-first (real data)
- Photos tab: add photo (URL) + categorize (before/after/general) + grid thumbnails + lightbox modal
And on server:
- POST endpoints for notes and attachments
- Audit logging for create actions
- touchClient(clientId) updates last_activity_at consistently

SHEETS TABS USED (from Ticket 10)
- Notes: id, created_at, entity_type, entity_id, author, body
- Attachments: id, created_at, entity_type, entity_id, file_url, file_type, category, uploaded_by
- Clients: includes last_activity_at
- Audit: existing audit log tab (do not change existing headers if already set up)

DELIVERABLES (SERVER)
1) Helper: touchClient(clientId)
- Updates Clients.last_activity_at to now ISO for given clientId
- Must NOT reorder rows.
- Finds the client row by id and updates ONLY the last_activity_at cell.
- Also updates updated_at if you are already maintaining it; if not, only last_activity_at is required for Ticket 13.

2) POST /api/notes (auth required)
Body:
{
  entity_type: "client" | "job" | "quote" | "visit" | "request",
  entity_id: string,
  author: string (optional; default "admin"),
  body: string (required)
}
Behavior:
- Validate body non-empty (trim)
- Create id: NOTE-{timestamp}
- created_at = now ISO
- Append row to Notes sheet
- Audit log:
  action = "CREATE_NOTE"
  entity_type/entity_id set to the note target (NOT the note id)
  field can be "" or "note"
  new_value can be first 120 chars of note
  source = "crm"
- If entity_type == "client": touchClient(entity_id)
- Respond:
  { ok: true, note: { id, created_at, entity_type, entity_id, author, body } }

3) POST /api/attachments (auth required)
Body:
{
  entity_type: "client" | "job" | "quote" | "visit" | "request",
  entity_id: string,
  file_url: string (required),
  file_type: "image" | "pdf" | "other" (optional, inferred if missing),
  category: "before" | "after" | "general" (default "general"),
  uploaded_by: string (optional; default "admin")
}
Behavior:
- Validate file_url:
  - must start with http:// or https://
- Infer file_type if not provided:
  - endsWith .png/.jpg/.jpeg/.webp/.gif -> image
  - endsWith .pdf -> pdf
  - else other
- Create id: ATT-{timestamp}
- created_at = now ISO
- Append row to Attachments sheet
- Audit log:
  action = "CREATE_ATTACHMENT"
  entity_type/entity_id = attachment target
  field = "file_url"
  new_value = file_url
  source = "crm"
- If entity_type == "client": touchClient(entity_id)
- Respond:
  { ok: true, attachment: {...} }

4) Audit logging must be fire-and-forget
- Implement a helper logAudit({actor, action, entity_type, entity_id, field, old_value, new_value, note, source, request_id})
- Wrap in try/catch; failures only console.error.

5) OPTIONAL (Nice): request_id correlation
- Generate request_id for each API call:
  - REQ-{timestamp}-{rand}
- Pass into audit rows.
